  What's being measured:
    NDA/shmem:  TLV encode → SHA-256 → mmap write → SetEvent → server processes
                → mmap write → SetEvent → client reads. No JSON parsing anywhere.
    NDA/stdio:  TLV encode → SHA-256 → pipe write → pipe read → server processes
                → pipe write → pipe read → TLV decode. Same binary encoding, pipes for transport.
    JSON/shmem: serde_json stringify → mmap write → SetEvent → server parses
                → mmap write → SetEvent → client JSON parses. Same shmem, JSON encoding cost.
    JSON/stdio: serde_json stringify → pipe write → thread recv → channel send →
                serde_json parse → handle → serde_json stringify → pipe write →
                pipe read → JSON parse. Two JSON serialize+parse cycles per request.
    JSON/HTTP:  serde_json stringify → HTTP POST → TCP write → Axum router →
                middleware stack → serde_json parse → handle → serde_json
                stringify → HTTP response → TCP read → JSON parse.
    Node/stdio: JSON.stringify → stdin write → Node.js readline → JSON.parse →
                handleRequest → JSON.stringify → stdout write → readline parse.
    Node/HTTP:  JSON.stringify → HTTP POST → TCP write → Node.js http server →
                JSON.parse → handleRequest → JSON.stringify → HTTP response →
                TCP read → JSON parse.
    NDA/HTTP:   TLV encode → SHA-256 → HTTP POST (octet-stream) → TCP write →
                Axum binary endpoint → TLV decode → process → TLV encode →
                SHA-256 → HTTP response → TCP read → TLV decode.

  Shmem buffer limits: input ≤ 4080 bytes, output ≤ 61440 bytes
  (4KB input / 61KB output — sufficient for typical MCP tool calls)
