========================================================================
  SUMMARY
========================================================================

  NDA-binary/shmem avg: 0.008 ms   (binary TLV frame parse, Win32 events)
  JSON-RPC/stdio avg:   0.022 ms   (serde_json + pipe + thread channel)
  Overall avg speedup:  2.7x faster (NDA vs stdio JSON-RPC)
  Overall p99 speedup:  1.4x faster

  What's being measured:
    NDA path:   TLV encode → SHA-256 → mmap write → SetEvent → server processes
                → mmap write → SetEvent → client reads. No JSON parsing anywhere.
    Stdio path: JSON stringify → pipe write → thread recv → channel send →
                serde_json parse → handle → serde_json stringify → pipe write →
                pipe read → JSON parse. Two JSON serialize+parse cycles per request.

  Shmem buffer limits: input ≤ 4086 bytes, output ≤ 61440 bytes
  (4KB input / 61KB output — sufficient for typical MCP tool calls)
